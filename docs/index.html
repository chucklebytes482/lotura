Lotura — Web Panduan

Sinkronisasi 2 arah multi-folder perangkat Android dengan Google Drive dan GitHub. Seluruh keterangan teknis, pengaturan jadwal, serta panduan setup dipusatkan di halaman ini agar antarmuka aplikasi tetap bersih dan ringkas.

Unduh APK Terbaru (GitHub Releases) Panduan Setup Google Cloud OAuth

Drive Real-Time + Ekspor Docs

FileObserver memantau perubahan lokal secara langsung ketika Anda menyunting file memakai Pilcrow MD, Google Docs, atau editor lain. Berkas native Google Docs/Sheets/Slides diekspor otomatis ke .docx, .xlsx, dan .pptx saat sinkronisasi serta diunggah balik ketika disunting lokal.

Multi-Akun GitHub (PAT)

Setiap pasangan folder perangkat dapat ditautkan ke 1 akun GitHub dan 1 repositori beserta branch dan subfolder. Fine-grained Personal Access Token (PAT) dienkripsi menggunakan Android Keystore AES-256-GCM dan disimpan terpisah di perangkat.

Anti Kehilangan Data

Pilih kebijakan penghapusan per pasangan folder: Dua Arah (hapus di satu sisi akan memindahkan file Drive ke Trash / menghapus di sisi lain) atau Mode Aman (tidak pernah menghapus otomatis). Saat terjadi konflik, versi terbaru menang dan versi kalah diamankan sebagai nama (konflik YYYYMMDD-HHmmss).ext.

Jadwal Sinkronisasi Terjadwal

Ketuk kartu prioritas #1 Sinkronisasi di Beranda untuk memilih jadwal sinkronisasi otomatis. Tanpa sakelar on/off yang membingungkan, aplikasi menyediakan empat pilihan interval:

Interval Rekomendasi Penggunaan
5 menit Khusus sesi penyuntingan sangat aktif lintas perangkat (konsumsi baterai lebih tinggi).
15 menit (Default) Pilihan standar paling seimbang antara responsivitas, hemat baterai, dan batas minimum WorkManager Android.
4 jam Cocok untuk arsip catatan harian yang tidak sering berubah.
24 jam Cadangan harian ringan untuk koleksi dokumen statis.

Cara Mulai Cepat

  1. Unduh APK arm64-v8a terbaru dari tombol GitHub Releases di atas dan verifikasi checksum pada berkas CHECKSUMS.txt.
  2. Aktifkan izin Akses Semua File (MANAGE_EXTERNAL_STORAGE) agar editor pihak ketiga seperti Pilcrow MD & Google Docs bisa langsung menyunting folder lokal tanpa duplikasi.
  3. Hubungkan 1 akun Google utama (AuthorizationClient, scope penuh https://www.googleapis.com/auth/drive pada mode OAuth Testing pribadi).
  4. Jika ingin menautkan repositori GitHub, buat Fine-grained PAT dengan izin Repository Contents (Read & Write) dan Metadata (Read-only), lalu tambahkan di tab Akun.
  5. Tambahkan Pasangan Folder baru di Beranda, pilih folder lokal, folder Drive, kebijakan hapus, dan opsional repositori GitHub beserta interval auto-commit terjadwal.

Batasan & Catatan Teknis

  • Tema Otomatis Sistem: Tampilan terang/gelap Lotura selalu mengikuti pengaturan sistem Android tanpa menu pemilih tema tambahan.
  • Batas Ukuran File GitHub: Berkas lokal melebihi 45 MB otomatis dilewati saat commit GitHub (tetap disinkronkan penuh ke Google Drive).
  • Optimasi Baterai OEM: Nonaktifkan pembatasan baterai latar belakang untuk Lotura pada MIUI/HyperOS, ColorOS, atau OneUI agar SyncForegroundService dan WorkManager berjalan stabil.
  • Aturan Pengecualian (Ignore Rules): Mendukung pola glob per pasangan folder (seperti .git/, *.tmp, *.swp, .DS_Store).
