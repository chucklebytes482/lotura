Panduan & Unduhan Resmi Lotura

Sinkronkan Google Drive & GitHub ke Perangkat Android

Hubungkan akun, centang file yang Anda mau, lalu unduh atau unggah secara manual. Tanpa server perantara.

Unduh Aplikasi (APK)

Versi terbaru untuk perangkat Android

Unduh APK 1. Persiapan 2. Hubungkan akun 3. Pilih file 4. Download & Upload 5. Hapus akun Keamanan

1. Persiapan

  1. Izin akses semua file: Beranda menampilkan tombol Beri izin jika belum aktif. Lotura butuh izin ini untuk membaca dan menulis folder lokal.
  2. Koneksi internet: dibutuhkan saat memuat pohon file, mengunduh, dan mengunggah.

Lokasi folder di perangkat

Sumber Lokasi di perangkat
Akun Google Drive /storage/emulated/0/google drive/<email>/
Repo GitHub /storage/emulated/0/github/<username>/<repo>/

2. Hubungkan akun

Google Drive

  1. Di Beranda, ketuk Hubungkan akun Google Drive.
  2. Pilih akun Google dan berikan izin. Anda bisa menambah lebih dari satu akun.
  3. Lotura memuat 3 level folder pertama. Folder yang lebih dalam dimuat saat dibuka.

GitHub

  1. Di Beranda, ketuk Tambah akun GitHub.
  2. Tempel fine-grained personal access token dengan izin Contents: Read and write ke repo yang ingin disinkronkan, lalu ketuk Simpan.
  3. Semua repo di akun itu otomatis muncul, masing-masing sebagai folder sendiri. Repo yang diarsipkan diberi label Archived.

3. Pilih file

  • Ketuk panah di sebelah akun atau repo untuk membuka pohonnya.
  • Centang file atau folder. Mencentang folder juga mencentang seluruh isinya.
  • Dokumen Google (Docs, Sheets, Slides) ditandai Dokumen Google · selalu ditransfer. Ukurannya tidak diketahui, jadi dokumen ini selalu ditransfer ulang.
  • Ketuk ikon muat ulang untuk mengambil daftar terbaru dari Drive atau GitHub.

4. Download & Upload

  • Download menyalin item yang dicentang dari Drive atau GitHub ke folder lokal.
  • Upload mengirim item yang dicentang dari folder lokal ke Drive atau GitHub.
  • Perbandingan hanya memakai ukuran file. File dengan ukuran sama dilewati. Jika ukuran berbeda, file ditransfer.
  • Hasil setiap operasi tercatat di tab Log.
  • Batal menghapus semua centang tanpa menjalankan apa pun.
Batasan upload: Upload hanya mengirim file yang sudah ada di pohon. File baru di folder lokal harus berada di dalam folder yang sudah ada di pohon. Muat ulang pohon setelah menambah folder baru.

5. Hapus akun

  • Ketuk ikon hapus di kanan header akun Drive untuk memutuskan akun tersebut dari Lotura.
  • Untuk GitHub, ketuk ikon hapus di header akun GitHub. Repo di akun itu ikut dihapus dari daftar.
  • Menghapus akun hanya memutus koneksi di Lotura. Berkas di perangkat maupun di Drive atau GitHub tidak ikut terhapus.
Setelah pembaruan aplikasi: akun Google Drive perlu disambungkan ulang. Akun GitHub perlu ditambahkan ulang.

Privasi & keamanan

  • Sinkronisasi berjalan langsung dari ponsel Anda ke Google Drive dan GitHub tanpa server perantara.
  • Token akses Google Drive dan token GitHub disimpan terenkripsi di perangkat Anda.
