Salin file antara HP Android, Google Drive, dan GitHub

Buka akun Drive atau repositori GitHub untuk menelusuri dan mengelola file yang tersimpan di remote.

Unduh Aplikasi (APK)

Versi terbaru untuk HP Android

1. Sebelum mulai 2. Sambungkan akun 3. Melihat folder 4. Unduh dan unggah 5. Jelajahi dan edit file 6. Putuskan akun

1. Sebelum mulai

  • Saat aplikasi meminta izin, pilih izinkan akses ke semua file. Lotura perlu izin ini agar bisa menyimpan file di HP Anda.
  • Pastikan HP terhubung ke internet.

2. Sambungkan akun

Google Drive

  1. Di layar utama, ketuk Sambungkan Google Drive.
  2. Pilih akun Google Anda, lalu izinkan akses. Anda bisa menyambungkan lebih dari satu akun.

GitHub

  1. Di layar utama, ketuk Tambahkan akun GitHub.
  2. Buat kode akses di situs GitHub dengan izin untuk membaca dan mengubah isi repo. Tempel kode itu di Lotura, lalu ketuk Sambungkan.
  3. Repo yang dapat dibaca oleh PAT akan muncul. Repo yang diarsipkan hanya bisa dijelajahi dan diunduh.

Contoh tampilan kartu akun

Kartu Google Drive hanya menampilkan alamat email. Kartu GitHub hanya menampilkan username.

nama@contoh.com
username-anda

3. Melihat folder

  • Pilih tab Google Drive atau GitHub, lalu ketuk akun Drive atau nama repo GitHub.
  • Ketuk folder untuk membukanya. Gunakan panah kembali untuk naik satu tingkat. Lotura menampilkan isi remote saja, bukan salinan di HP.
  • Di GitHub, Lotura membuka cabang bawaan repo. Ketuk ikon muat ulang untuk memperbarui isi folder atau daftar repo.
  • File dan folder berawalan titik, seperti .env dan .github, tidak ditampilkan.

4. Unduh dan unggah

  • Ketuk ikon Unduh di samping file atau folder. Folder disalin bersama subfoldernya, tanpa item tersembunyi.
  • Unduhan GitHub masuk ke /storage/emulated/0/github/<pemilik>/<repo>/. Unduhan Drive masuk ke /storage/emulated/0/google drive/<email>/. Unduhan tidak menimpa file atau folder setempat.
  • Google Docs, Sheets, dan Slides diunduh sebagai file Office. Pintasan Drive, symlink GitHub, submodule, dan format Drive tanpa format ekspor tidak ikut diunduh.
  • Buka folder tujuan, ketuk ikon Unggah file, lalu pilih satu atau beberapa file lewat pemilih Android. Nama file tersembunyi ditolak; file remote bernama sama tidak ditimpa. Batas unggah GitHub: 45 MiB per file.

5. Buat folder dan hapus item

  • Ketuk ikon Buat folder baru. Folder langsung dibuat di Drive atau di cabang GitHub yang aktif. GitHub memakai file penanda .gitkeep untuk folder kosong.
  • Ikon Hapus meminta konfirmasi. Di Drive, item masuk ke Sampah. Di GitHub, penghapusan tercatat sebagai commit. Menghapus folder juga menghapus isinya, termasuk item tersembunyi.
  • Fitur Sinkron lama sudah tidak ada. Mengubah hasil unduhan di HP tidak mengubah file remote.

6. Putuskan akun

  • Ketuk ikon putuskan di baris akun GitHub atau Google Drive, untuk memutuskan akun dari Lotura.
  • Memutuskan akun tidak menghapus file Anda, baik di HP maupun di Google Drive atau GitHub.
