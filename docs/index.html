Sinkronisasi Folder Android ↔ Google Drive & GitHub

Kelola dan sinkronkan folder catatan, dokumen Markdown, maupun repositori Anda secara 2 arah langsung dari penyimpanan perangkat Android tanpa server perantara.

Unduh APK Identitas Kartu Hubungkan Akun Tambah Pasangan Sinkronisasi Detail & File Keamanan

1. Pembeda Visual Google Drive vs GitHub

Setiap kartu pasangan di Beranda, layar Tambah Pasangan, dan layar Detail dirancang dengan warna aksen serta ikon khusus agar langsung dikenali dalam sekejap:

Google Drive

Aksen Biru-Cyan dengan ikon segitiga pita Drive. Cocok untuk folder catatan harian atau arsip dokumen pribadi.

/storage/emulated/0/Documents/<FolderDrive>
GitHub

Aksen Ungu-Violet dengan ikon khas GitHub. Jalur perangkat menyertakan nama repositori agar folder bernama sama antar repo tidak saling menimpa.

/storage/emulated/0/Documents/<NamaRepo>/<Folder>

2. Persiapan Izin & Akun

  1. Izin Akses Semua File: Ketuk tombol Aktifkan pada spanduk di Beranda agar Lotura dapat membaca dan menyimpan berkas di dalam Documents/.
  2. Akun Google Drive: Ketuk kartu Google Drive di Beranda atau buka tab Akun, lalu masuk dengan akun Google Anda.
  3. Akun GitHub (Fine-Grained PAT): Buka tab Akun → ketuk Tambah Akun GitHub, lalu tempel Fine-Grained Personal Access Token dengan izin Contents (Read and write) serta Metadata (Read-only). Nama akun terdeteksi otomatis dari profil GitHub Anda.

3. Menambah Pasangan Folder & Anti-Duplikat

  1. Tekan tombol + di kanan bawah Beranda.
  2. Pilih sumber Google Drive atau GitHub.
  3. Untuk Google Drive, pilih 1 folder tujuan (atau buat folder baru langsung dari pemilih). Untuk GitHub, pilih akun, pilih repositori, lalu pilih 1 folder di dalam repositori tersebut.
  4. Folder yang sudah pernah dipasangkan otomatis ditandai lencana Terpasang dan tidak dapat dipilih ulang (Anda tetap bisa membuka ke dalamnya jika ingin memasangkan subfolder lain yang belum terpasang).
  5. Ketuk Simpan Pasangan Folder. Folder lokal di Documents/ dibuat otomatis.
Contoh Sumber Folder Perangkat Otomatis
Google Drive: Catatan Kerja /storage/emulated/0/Documents/Catatan Kerja
GitHub: chucklebytes482/Petapikir@main / panduan /storage/emulated/0/Documents/Petapikir/panduan
GitHub: chucklebytes482/Petapikir@main / docs/sub /storage/emulated/0/Documents/Petapikir/docs/sub

4. Sinkronisasi 2 Arah Manual per Folder

Lotura tidak menjalankan jadwal latar belakang tersembunyi. Anda memegang kendali penuh kapan setiap folder disinkronkan:

  • Ketuk tombol Sinkron di sisi kanan kartu pasangan pada Beranda.
  • Saat sinkronisasi berlangsung, banner keterangan "Tunggu hingga selesai agar sinkronisasi berhasil" tampil pada kartu pasangan hingga proses tuntas.
  • Perubahan tambah, ubah, dan hapus di perangkat maupun di cloud/GitHub akan diselaraskan secara 2 arah. Jika terjadi konflik suntingan bersamaan, versi konflik diamankan agar tidak hilang.
Tips: Biarkan Lotura tetap terbuka saat menyinkronkan folder berukuran besar agar seluruh berkas selesai terunggah dan terunduh dengan utuh.

5. Layar Detail Terpadu & Penjelajah File Langsung

Mengetuk kartu pasangan di Beranda langsung membuka layar Detail yang menggabungkan ringkasan pasangan dan penjelajah berkas dalam satu halaman:

  • Ringkasan di Bagian Atas: Menampilkan identitas penyedia, sumber Google Drive atau GitHub, lokasi lengkap Folder Perangkat, jumlah berkas, waktu sinkron terakhir, serta tombol Hapus Pasangan.
  • Penjelajah File Langsung: Ketuk folder untuk masuk ke subfolder, ketuk berkas untuk langsung membukanya di aplikasi editor pilihan Anda (seperti Pilcrow MD atau Google Docs).
  • Aksi Cepat & Pilih Banyak: Gunakan tombol Catatan .md dan Folder Baru untuk membuat item baru, bilah pencarian untuk menyaring nama berkas, atau tekan tahan berkas/folder untuk memindah maupun menghapus banyak item sekaligus.
  • Riwayat Log: Seluruh riwayat aktivitas sinkronisasi dan penyaringan galat/konflik tersedia di tab Log pada bilah navigasi bawah.

6. Privasi & Keamanan Kredensial

  • Seluruh komunikasi berjalan langsung dari ponsel Anda ke API resmi Google Drive dan GitHub melalui HTTPS tanpa server perantara.
  • Token akses Google Drive dan Fine-Grained PAT GitHub disimpan secara terenkripsi menggunakan Android Keystore (AES-256-GCM) di perangkat Anda sendiri.
  • Menghapus pasangan dari Lotura hanya menghapus tautan sinkronisasi dari daftar aplikasi dan tidak menghapus berkas asli Anda di perangkat maupun di cloud.
