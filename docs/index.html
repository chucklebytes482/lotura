Lotura — Web Panduan

Sinkronisasi 2 arah manual per folder antara perangkat Android dengan Google Drive atau 1 folder khusus di GitHub. Dirancang ringan tanpa layanan latar belakang maupun jadwal otomatis, agar Anda bebas menyunting dokumen di ponsel dengan cepat dan rapi.

2 Jenis Pasangan 2 Arah

Setiap pasangan bersifat eksklusif: Perangkat ↔ Google Drive atau Perangkat ↔ 1 Folder GitHub. Sinkronisasi berjalan 2 arah saat Anda mengetuk tombol sinkron pada kartu folder di Beranda.

Khusus 1 Folder di GitHub

Untuk GitHub, Anda memilih tepat 1 folder di dalam repositori (misalnya docs) lewat pemilih folder interaktif. Root repositori dikunci agar berkas kode tidak ikut disinkronkan ke ponsel.

Folder Perangkat Otomatis

Tidak perlu memilih jalur perangkat secara manual. Semua folder otomatis ditempatkan di direktori Documents dengan nama yang sama persis seperti sumbernya, dan langsung dibuat jika belum ada.

Lokasi Folder Default di Perangkat

Setiap pasangan folder otomatis disimpan di dalam folder Documents perangkat menggunakan nama folder dari Google Drive atau GitHub: 

/storage/emulated/0/Documents/<nama-folder>
Tipe Pasangan Nama Pasangan Folder di Perangkat
Perangkat ↔ Google Drive Catatan /storage/emulated/0/Documents/Catatan
Perangkat ↔ GitHub lotura/docs /storage/emulated/0/Documents/docs

Cara Mulai Cepat

  1. Unduh dan pasang APK terbaru melalui tombol Unduh APK Terbaru di atas.
  2. Aktifkan izin Akses Semua File saat diminta agar aplikasi editor seperti Pilcrow MD atau Google Docs dapat langsung mengedit berkas lokal.
  3. Hubungkan akun Google Drive lewat kartu status akun di Beranda atau tab Akun.
  4. Untuk GitHub, buat Fine-grained PAT dengan izin Repository Contents (Read & Write) dan Metadata (Read-only), lalu masukkan di tab Akun. Label akun terisi otomatis dari profil GitHub Anda.
  5. Ketuk tombol + di Beranda lalu pilih sumber (folder Google Drive atau 1 folder GitHub). Folder perangkat di Documents langsung disiapkan otomatis saat disimpan.
  6. Ketuk ikon Sinkron pada kartu folder di Beranda kapan pun Anda ingin menyinkronkan folder tersebut dua arah.

Catatan Penggunaan

  • Hemat Baterai: Tidak ada layanan latar belakang, pemantau berkas, maupun jadwal periodik — sinkronisasi hanya berjalan saat Anda menekan tombol sinkron pada folder yang dipilih.
  • Konflik & Google Docs: Jika berkas berubah bersamaan di kedua sisi, versi terbaru menang dan versi sebelumnya diamankan dengan akhiran (konflik ...). Berkas Google Docs/Sheets/Slides otomatis diekspor ke .docx, .xlsx, dan .pptx.
  • Tema Otomatis Sistem: Tampilan terang/gelap selalu mengikuti pengaturan sistem Android tanpa menu pemilih tema tambahan.
  • Batas Ukuran File GitHub: Berkas lokal melebihi 45 MB otomatis dilewati saat sinkronisasi GitHub.
