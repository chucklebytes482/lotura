Lotura — Web Panduan

Sinkronisasi 2 arah manual per folder antara perangkat Android dengan Google Drive atau 1 folder khusus di GitHub. Dirancang ringan tanpa layanan latar belakang maupun jadwal otomatis, agar Anda bebas menyunting dokumen di ponsel dengan cepat dan aman.

Unduh APK Terbaru (GitHub Releases) Panduan Setup Google Cloud OAuth

2 Jenis Pasangan 2 Arah

Setiap pasangan bersifat eksklusif: Folder Perangkat ↔ Google Drive atau Folder Perangkat ↔ 1 Folder GitHub. Seluruh sinkronisasi berjalan 2 arah dan dipicu langsung melalui tombol sinkron pada masing-masing kartu folder di Beranda.

Khusus 1 Folder di GitHub

Untuk GitHub, Anda wajib memilih tepat 1 folder di dalam repositori (misalnya docs) lewat pemilih folder interaktif. Root repositori dikunci agar berkas kode dan konfigurasi teknis tidak ikut disinkronkan ke ponsel.

Identitas & Folder Otomatis

Nama pasangan, label akun GitHub, dan nama folder di perangkat otomatis mengikuti nama sumbernya di Google Drive atau GitHub. Jika folder bernama sama belum ada pada jalur perangkat yang dipilih, Lotura langsung membuatnya secara otomatis.

Ringkasan Pasangan Folder

Tipe Pasangan Penamaan Otomatis Folder Perangkat
Perangkat ↔ Google Drive Nama folder Google Drive (mis. Catatan) <jalur-pilihan>/Catatan (dibuat otomatis jika belum ada)
Perangkat ↔ GitHub nama-repo/folder (mis. lotura/docs) <jalur-pilihan>/docs (dibuat otomatis jika belum ada)

Cara Mulai Cepat

  1. Unduh APK arm64-v8a terbaru dari tombol GitHub Releases di atas dan verifikasi checksum pada berkas CHECKSUMS.txt.
  2. Aktifkan izin Akses Semua File (MANAGE_EXTERNAL_STORAGE) agar editor pihak ketiga seperti Pilcrow MD & Google Docs bisa langsung menyunting berkas lokal di tempat.
  3. Hubungkan akun Google Drive lewat kartu status akun di Beranda atau tab Akun.
  4. Untuk GitHub, buat Fine-grained PAT dengan izin Repository Contents (Read & Write) dan Metadata (Read-only), lalu masukkan di tab Akun. Label akun terisi otomatis dari profil GitHub Anda dan token dienkripsi dengan Android Keystore AES-256-GCM.
  5. Ketuk tombol + di Beranda, pilih 1. Sumber (Google Drive atau 1 folder GitHub), lalu pilih 2. Jalur di Perangkat. Folder lokal bernama sama otomatis disiapkan saat disimpan.
  6. Ketuk ikon Sinkron pada masing-masing kartu folder di Beranda kapan pun Anda ingin menyinkronkan folder tersebut dua arah.

Batasan & Catatan Teknis

  • Hemat Baterai (Tanpa Layanan Latar Belakang): Tidak ada layanan latar belakang, pemantau berkas, maupun jadwal periodik — sinkronisasi hanya berjalan saat Anda menekan tombol sinkron pada kartu folder yang diinginkan.
  • Konflik & Ekspor Google Docs: Jika file berubah bersamaan di kedua sisi, versi terbaru menang dan versi kalah diamankan sebagai nama (konflik YYYYMMDD-HHmmss).ext. Berkas native Google Docs/Sheets/Slides otomatis diekspor ke .docx, .xlsx, dan .pptx.
  • Tema Otomatis Sistem: Tampilan terang/gelap Lotura selalu mengikuti pengaturan sistem Android tanpa menu pemilih tema tambahan.
  • Batas Ukuran File GitHub: Berkas lokal melebihi 45 MB otomatis dilewati saat commit GitHub.
  • Verifikasi Keaslian APK (Kunci Permanen): Setiap rilis resmi ditandatangani kunci permanen dengan sertifikat SHA-256 64:22:47:D9:76:99:BF:DB:0E:E4:C1:93:69:BF:50:10:81:CA:3F:B4:24:DE:D7:1F:E6:39:97:89:20:19:94:8E (cocokkan dengan berkas CERT_FINGERPRINT.txt di GitHub Releases).
