Salin file antara HP Android, Google Drive, dan GitHub

Sambungkan akun Anda, lalu ketuk ikon unduh atau unggah pada folder yang ingin Anda salin.

Unduh Aplikasi (APK)

Versi terbaru untuk HP Android

1. Sebelum mulai 2. Sambungkan akun 3. Melihat folder 4. Unduh dan unggah 5. Jelajahi dan edit file 6. Putuskan akun

1. Sebelum mulai

  • Saat aplikasi meminta izin, pilih izinkan akses ke semua file. Lotura perlu izin ini agar bisa menyimpan file di HP Anda.
  • Pastikan HP terhubung ke internet.

2. Sambungkan akun

Google Drive

  1. Di layar utama, ketuk Hubungkan akun Google Drive.
  2. Pilih akun Google Anda, lalu izinkan akses. Anda bisa menyambungkan lebih dari satu akun.

GitHub

  1. Di layar utama, ketuk Tambah akun GitHub.
  2. Buat kode akses di situs GitHub dengan izin untuk membaca dan mengubah isi repo. Tempel kode itu di Lotura, lalu ketuk Simpan.
  3. Semua repo di akun itu akan muncul. Repo yang sudah diarsipkan diberi tanda Archived.

Contoh tampilan kartu akun

Kartu Google Drive hanya menampilkan alamat email. Kartu GitHub hanya menampilkan username.

nama@contoh.com
username-anda

3. Melihat folder

  • Setiap folder utama di Google Drive dan setiap repo GitHub tampil sebagai kartu di layar utama.
  • Ikon di kartu menunjukkan hasil terakhir: centang berarti berhasil, tanda seru berarti sebagian berhasil, dan silang berarti gagal.
  • Ketuk kartu untuk membuka detailnya. Di sana ada tombol Download dan Unggah, tombol Jelajahi file, serta status sync terakhir.
  • Untuk memperbarui daftar, ketuk ikon muat ulang di bagian akun.
  • Dokumen Google (Docs, Sheets, Slides) selalu disalin ulang, karena ukurannya tidak bisa dicek.

4. Unduh dan unggah

  • Unduh menyalin folder dari Google Drive atau GitHub ke HP Anda.
  • Unggah menyalin folder dari HP Anda ke Google Drive atau GitHub. File baru di dalam folder itu ikut tersalin.
  • Lotura hanya menyalin file yang berbeda. File yang sama akan dilewati.
  • Selama proses berjalan, tombol tidak bisa ditekan. Tunggu sampai selesai.

5. Jelajahi dan edit file

  • Di layar detail repo GitHub atau folder Drive, ketuk Jelajahi file. Isinya tampil sebagai daftar: folder dulu, lalu file.
  • Ketuk folder untuk masuk. Tombol kembali naik satu folder, dan kembali ke detail saat sudah di folder paling atas.
  • Ketuk file teks untuk membuka editor. Ubah isinya, lalu tunggu sebentar. Perubahan disimpan otomatis ke HP.
  • Dari daftar file, Anda bisa membuat file atau folder baru, mengganti nama, dan menghapus. Menghapus folder ikut menghapus isinya.
  • Perubahan di repo otomatis di-push ke branch main di GitHub, dikumpulkan sekitar 3 detik lalu dikirim sebagai satu commit. Tidak ada tombol simpan.
  • GitHub dicek tiap 60 detik. Perubahan dari GitHub otomatis ditarik ke HP. Berkas yang sedang dibuka di editor ditarik setelah editor ditutup.
  • Riwayat per berkas: di editor, ketuk Riwayat untuk melihat commit yang pernah mengubah berkas itu. Ketuk satu versi untuk melihat isinya, lalu Pulihkan untuk menjadikannya isi berkas sekarang. Pemulihan ikut ter-push ke GitHub sebagai perubahan baru.
  • Jika file yang sama berubah di HP dan di GitHub, Lotura melaporkan konflik dan tidak menimpa salah satunya.
  • File di atas 45 MB dilewati. Berkas biner (gambar, APK, dan sejenisnya) serta berkas di atas 2 MB tidak bisa dibuka di editor.
  • Auto-sync hanya berjalan selama aplikasi terbuka atau aktif di latar belakang. Folder Google Drive tidak ikut.

6. Putuskan akun

  • Ketuk ikon hapus di bagian akun untuk memutuskan akun dari Lotura.
  • Memutuskan akun tidak menghapus file Anda, baik di HP maupun di Google Drive atau GitHub.
Setelah pembaruan aplikasi: sambungkan kembali akun Google Drive Anda. Tambahkan kembali akun GitHub Anda.
