1. Arti Ikon & Warna Kartu Pasangan

Kartu pasangan di Beranda Lotura dibuat ringkas tanpa keterangan teks berlebih. Warna, garis tepi kiri, dan ikon besar langsung menunjukkan sumber beserta hasil sinkronisasi terakhir:

Pembeda Sumber (Google Drive vs GitHub)

Google Drive (Biru-Cyan)

Garis sisi kiri dan ikon pita segitiga berwarna Biru-Cyan menandakan folder yang terhubung ke Google Drive Anda.

Documents/Google Drive/<NamaFolder>
GitHub (Ungu-Violet)

Garis sisi kiri dan ikon khas GitHub berwarna Ungu-Violet menandakan folder dari repositori GitHub Anda.

Documents/GitHub/<NamaRepo>/<NamaFolder>

Legenda Ikon Baris Status & Aksi

Angka di samping setiap ikon menunjukkan jumlah berkas pada sinkronisasi terakhir. Warna ikon akan menyala tegas bila angkanya lebih dari 0, dan redup bila 0.

Unggah (Awan Panah Atas) Jumlah berkas dari perangkat Anda yang diunggah ke Google Drive atau GitHub.
Unduh (Awan Panah Bawah) Jumlah berkas yang diunduh (termasuk dokumen yang diekspor) ke folder perangkat Anda.
File Dihapus (Tempat Sampah) Jumlah berkas yang ikut dihapus saat menyelaraskan penghapusan 2 arah.
Konflik (Segitiga Peringatan) Jumlah berkas yang berubah bersamaan di kedua sisi. Salinan konflik disimpan terpisah agar tidak hilang.
Tombol Sinkron Ketuk untuk memulai sinkronisasi 2 arah pada folder tersebut. Ikon berputar saat proses berjalan.
Galat Sinkronisasi (Tanda Seru Merah) Muncul di samping waktu bila sinkronisasi terakhir gagal. Buka tab Log untuk rinciannya.
Mode Pilih (Ikon Centang) Muncul saat kartu ditekan tahan untuk memilih satu atau beberapa pasangan yang ingin dihapus.

2. Persiapan Izin & Akun

  1. Izin Akses Semua File: Ketuk tombol Aktifkan pada spanduk di Beranda agar Lotura dapat membaca dan menyimpan berkas di dalam folder Documents/ perangkat Anda.
  2. Akun Google Drive: Ketuk kartu Google Drive di Beranda atau buka tab Akun, lalu masuk dengan akun Google Anda.
  3. Akun GitHub: Buka tab Akun → ketuk Tambah Akun GitHub, lalu tempel token akses pribadi (Fine-Grained Personal Access Token) dengan izin baca & tulis isi repositori. Nama akun terdeteksi otomatis.

3. Menambah Pasangan Folder (Folder Utama & Anti-Duplikat)

  1. Tekan tombol + di kanan bawah Beranda.
  2. Pilih sumber Google Drive atau GitHub.
  3. Pilih 1 folder utama (tingkat teratas) di Drive Saya atau di dalam repositori GitHub. Anda tidak perlu memilih subfolder satu per satu karena seluruh subfolder di dalamnya otomatis ikut disinkronkan.
  4. Folder yang sudah pernah dipasangkan otomatis ditandai Terpasang dan dikunci agar tidak terpilih dua kali.
  5. Ketuk Simpan Pasangan Folder. Folder perangkat di dalam Documents/ akan dibuat otomatis mengikuti struktur sumbernya.
Contoh Sumber Lokasi Folder di Perangkat
Google Drive: Catatan Kerja /storage/emulated/0/Documents/Google Drive/Catatan Kerja
GitHub: akun-anda/Catatan / panduan /storage/emulated/0/Documents/GitHub/Catatan/panduan
GitHub: akun-anda/Catatan / arsip /storage/emulated/0/Documents/GitHub/Catatan/arsip

4. Sinkronisasi 2 Arah Manual per Folder

Lotura tidak menjalankan sinkronisasi latar belakang secara diam-diam. Anda memegang kendali penuh kapan setiap folder diselaraskan:

  • Ketuk tombol Sinkron di sisi kanan kartu pasangan pada Beranda.
  • Saat sinkronisasi berjalan, pemberitahuan "Tunggu hingga selesai agar sinkronisasi berhasil" tampil pada kartu hingga selesai.
  • Setelah selesai, angka di samping ikon Unggah, Unduh, Dihapus, dan Konflik langsung diperbarui sesuai hasil terbaru.
Tips: Biarkan Lotura tetap terbuka saat menyinkronkan folder berukuran besar agar seluruh berkas selesai terunggah dan terunduh dengan utuh.

5. Mengakses Berkas & Menghapus Pasangan

  • Membuka & Mengedit Berkas: Buka langsung folder Documents/Google Drive/ atau Documents/GitHub/<NamaRepo>/ melalui aplikasi manajer berkas ponsel maupun editor pilihan Anda (seperti aplikasi catatan Markdown atau dokumen). Setelah selesai menyunting, buka Lotura dan ketuk tombol Sinkron.
  • Menghapus Pasangan Folder: Tekan tahan kartu pasangan di Beranda hingga muncul tanda centang dan bilah pilihan di bagian atas, pilih kartu lain bila perlu, lalu ketuk ikon Hapus di pojok kanan bilah pilihan.
  • Melihat Riwayat & Galat: Buka tab Log pada bilah navigasi bawah untuk melihat daftar berkas yang baru disinkronkan atau memeriksa rincian apabila muncul ikon tanda seru merah.

6. Privasi & Keamanan

  • Seluruh sinkronisasi terhubung langsung dari ponsel Anda ke layanan Google Drive dan GitHub tanpa server perantara.
  • Kunci akses akun Google Drive dan GitHub Anda disimpan secara terenkripsi di dalam keamanan perangkat Anda sendiri.
  • Menghapus pasangan dari Lotura hanya memutuskan tautan sinkronisasi dari daftar aplikasi dan tidak menghapus berkas asli Anda di perangkat maupun di cloud.
